# Manual de Usuario Final

## 1. Introduccion
Este manual explica el uso general del sistema inmobiliario de Global Consultores Inmobiliarios y Servicios Integrales.

El sistema tiene dos areas principales:

1. Sitio publico.
2. Panel administrativo.

El sitio publico permite consultar propiedades y enviar solicitudes.

El panel administrativo permite administrar propiedades, agentes, catalogos, usuarios, ventas, comisiones, suscripciones, pagos de publicacion y solicitudes, segun los permisos asignados a cada usuario.

## 2. Requisitos para usar el sistema
- Navegador web actualizado.
- Conexion a internet.
- Credenciales de acceso para entrar al panel administrativo.

## 3. Acceso al sistema

### 3.1 Sitio publico
El sitio publico esta pensado para clientes y visitantes. Desde aqui se puede:

- Ver la pagina de inicio.
- Consultar el listado de propiedades.
- Abrir el detalle de una propiedad.
- Navegar por tipo de propiedad.
- Revisar la seccion de servicios.
- Revisar la seccion nosotros.
- Enviar solicitudes o mensajes de contacto.

### 3.2 Panel administrativo
Para ingresar al panel administrativo:

1. Abrir la opcion `Login`.
2. Escribir el correo electronico.
3. Escribir la contrasena.
4. Presionar `Iniciar sesion`.

Si el usuario tiene activado cambio de contrasena obligatorio, el sistema redirige a la pantalla de cambio de contrasena.

Si el usuario debe aceptar terminos y condiciones de primer ingreso, el sistema redirige a la pantalla de aceptacion antes de permitir el uso del panel.

## 4. Cambio de contrasena
Algunos usuarios pueden estar obligados a cambiar su contrasena al primer acceso.

Pasos:

1. Ingresar la nueva contrasena.
2. Confirmar la nueva contrasena si la pantalla lo solicita.
3. Guardar el cambio.
4. Iniciar sesion nuevamente si el sistema lo pide.

## 5. Aceptacion de terminos de primer ingreso
Si el usuario debe aceptar terminos:

1. Leer el texto mostrado.
2. Confirmar la aceptacion.
3. Continuar al panel administrativo.

La aceptacion queda registrada con:

- Usuario.
- Fecha y hora.
- Version del documento.
- Texto aceptado.

## 7. Modulo de propiedades
Este modulo permite registrar y actualizar inmuebles.

Funciones principales:

- Crear propiedad nueva.
- Editar propiedad existente.
- Activar o desactivar propiedad.
- Marcar o quitar destacada.
- Cerrar venta o cerrar renta.

Datos comunes de una propiedad:

- Titulo.
- Tipo de operacion.
- Tipo de propiedad.
- Zona.
- Agente.
- Precio.
- Area.
- Habitaciones.
- Banos.
- Estacionamientos.
- Direccion.
- Portada.
- Galeria de imagenes.

### 7.1 Crear una propiedad
Pasos generales:

1. Entrar a `Propiedades`.
2. Presionar `Nueva propiedad`.
3. Completar el formulario.
4. Subir la imagen de portada si se desea.
5. Subir imagenes de galeria si se desea.
6. Guardar.

### 7.2 Estados importantes de una propiedad
- `Activa`: la propiedad sigue habilitada en el sistema.
- `Inactiva`: la propiedad no debe operar normalmente.
- `Borrador`: aun no esta lista para publicacion.
- `Pendiente de pago`: requiere pago de publicacion o suscripcion.
- `Publicada`: visible en el sitio publico.
- `Vendida` o `Rentada`: ya fue cerrada comercialmente.

### 7.3 Recomendaciones de uso
- Verificar que la direccion y el precio sean correctos.
- Confirmar que el agente asignado sea el correcto.
- Revisar las imagenes antes de guardar.
- Confirmar el estado de publicacion antes de esperar verla en el sitio publico.

## 8. Modulo de agentes
Permite administrar a las personas que atienden o representan propiedades.

Funciones principales:

- Crear agente.
- Editar agente.
- Eliminar agente.
- Subir foto desde el equipo.

Datos comunes:

- Nombre.
- Cargo.
- Telefono.
- Correo.
- Foto.
- Especialidad.
- Estado.

## 9. Modulos de catalogos

### 9.1 Tipos
Se usa para registrar categorias como:

- Casa.
- Apartamento.
- Local comercial.
- Terreno.

### 9.2 Zonas
Se usa para organizar propiedades por ciudad o zona geografica.

### 9.3 Imagenes
Sirve como vista de apoyo para revisar el material grafico asociado a propiedades.

### 9.4 Planes
Se usa para administrar planes de publicacion, por ejemplo:

- Nombre del plan.
- Precio.
- Duracion.
- Limite de imagenes.
- Prioridad.
- Si permite destacada.

## 10. Modulo de suscripciones
Este modulo registra la relacion entre una propiedad y un plan de publicacion.

Funciones principales:

- Crear suscripcion.
- Editar suscripcion.
- Consultar vigencia.
- Revisar estado.

Datos comunes:

- Propiedad.
- Plan.
- Precio final.
- Fecha de inicio.
- Fecha de fin.
- Estado.
- Observaciones.
- Auto renovar.

## 11. Modulo de pagos de publicacion
Registra los pagos asociados a suscripciones o publicacion de propiedades.

Funciones principales:

- Crear pago.
- Consultar pagos registrados.
- Ver monto.
- Ver metodo de pago.
- Ver referencia.
- Ver estado del pago.

Recomendacion:

- Registrar el pago completo correspondiente al plan.
- Confirmar que la suscripcion quede con las fechas correctas y con estado actualizado.

## 12. Modulo de ventas
Permite registrar el cierre comercial de una propiedad.

Datos comunes:

- Propiedad.
- Agente.
- Cliente.
- Precio de cierre.
- Tipo de negocio.
- Fecha de cierre.
- Observaciones.

Cuando una propiedad se vende o se renta:

- Cambia su estado comercial.
- Puede generar comision.
- Puede dejar de estar disponible para nuevas operaciones.

## 13. Modulo de comisiones
Permite llevar el control de comisiones generadas por ventas o rentas.

En este sistema la comision fija comercial configurada es del `5%`.

Se recomienda revisar:

- Monto de cierre.
- Porcentaje aplicado.
- Monto calculado.
- Estado de pago de la comision.

## 14. Modulo de solicitudes
Este modulo administra los mensajes enviados desde el sitio publico.

Funciones principales:

- Ver solicitudes recibidas.
- Filtrar solicitudes.
- Ordenar por fecha.
- Cambiar estado entre `Abierta` y `Cerrada`.
- Eliminar solicitudes si el usuario tiene permiso.

Uso recomendado:

1. Revisar solicitudes nuevas.
2. Contactar al cliente.
3. Cambiar a `Cerrada` cuando la gestion finalice.

## 15. Modulo de usuarios
Permite administrar cuentas de acceso al panel.

Funciones principales:

- Crear usuario.
- Editar usuario.
- Activar o desactivar usuario.
- Definir si requiere aceptacion de terminos.

Datos comunes:

- Nombre completo.
- Identificacion.
- Correo.
- Contrasena.
- Rol.
- Estado.

## 16. Modulo de roles y permisos
Permite controlar lo que cada usuario puede ver o hacer.

Los permisos gestionados en el sistema son:

- `VER`
- `CREAR`
- `ELIMINAR`

Con este modulo se puede:

- Crear roles.
- Editar permisos de un rol.
- Asignar los permisos adecuados a cada tipo de usuario.

Ejemplo:

- Un usuario operativo puede ver propiedades y solicitudes.
- Un administrador puede ver y modificar todos los modulos.

## 17. Modulo de aceptaciones legales
Muestra el historial de aceptacion de terminos.

Funciones principales:

- Buscar por usuario.
- Filtrar por correo o codigo.
- Ver el texto aceptado.
- Imprimir el documento.
- Descargar PDF.

## 18. Sitio publico: flujo para clientes
Un visitante puede usar el sistema asi:

1. Entrar al inicio.
2. Abrir `Propiedades`.
3. Filtrar o revisar propiedades.
4. Abrir una propiedad especifica.
5. Revisar imagenes, precio, datos y agente.
6. Llenar el formulario de contacto.
7. Esperar seguimiento del equipo comercial.

## 19. Buenas practicas de uso
- Mantener actualizados precios, estados y fotografias.
- No compartir credenciales entre usuarios.
- Cerrar sesion al terminar.
- Revisar periodicamente solicitudes, suscripciones y pagos.
- Confirmar permisos antes de asignar un rol a un usuario.

## 20. Problemas frecuentes

### 20.1 No puedo entrar al panel
Verificar:

- Correo correcto.
- Contrasena correcta.
- Que el usuario este activo.

### 20.2 La propiedad no aparece en la web
Verificar:

- Que este activa.
- Que tenga estado de publicacion `Publicada`.
- Que no este vencida o pausada.

### 20.3 No veo una opcion del menu
Posibles causas:

- El usuario no tiene permiso `VER` para ese modulo.
- El rol asignado no incluye esa pantalla.

### 20.4 No puedo eliminar o crear registros
Posible causa:

- El usuario no tiene permiso `CREAR` o `ELIMINAR`.

## 21. Cierre de sesion
Para salir del sistema:

1. Abrir el menu lateral.
2. Presionar `Cerrar sesion`.

Esto ayuda a proteger la informacion cuando el equipo comparte equipos o trabaja desde oficinas abiertas.

## 22. Ubicacion del historial legal
El historial de aceptacion de terminos queda guardado en la base de datos, en la tabla:

`aceptaciones_terminos`
